## 为什么采用 JSON API

AV01 的页面只是运行入口，列表、标签、详情和播放授权都有结构化 API。直接使用 API 比等待前端渲染更稳定，也能保留分页总数、翻译字段和地区化封面信息。所有请求设 8 秒超时，并对白名单 ID/分类进行校验。

## 内容 API

| 功能 | 请求 |
| --- | --- |
| 地区和临时参数 | `files.iw01.xyz/edge/geo.js?json` |
| 首页标签 | `tags/by-score?page=1&limit=20` |
| 最新/热门 | `videos/types/{latest|hottest}` |
| 标签分类 | `videos/tag/{数字ID}` |
| 搜索 | `POST videos/search?lang=cn` |
| 详情 | `videos/{数字ID}` |

首页固定放“最新、热门”，再追加高分标签。标题、演员、导演、厂商和说明优先使用 `cn/tw/hk` 翻译。封面根据 geo 返回的 R2 状态、地区、token 和过期时间选择地址；geo 失败会保留内容并附带请求警告。

## 播放授权链路

1. 详情返回 `type: "webview"` 的媒体项，把数字 ID 和作品编码替换进 `playerContent.loadUrl`。
2. `playerContent` 使用 geo 的 `token_v2`、`expires`、`ip` 和可选 `comp` 调用 `cdn-access`。
3. 取得短期 `access_token` 后构造站点 HLS 主清单，并带当前 WebView 的 User-Agent 和 Referer。
4. `GMSubs` 识别 AV01 token 主清单，把 token 传播到相对 variant URI，并把授权清单请求限定到合法 AV01/iw01 域名。
5. 冷 token 最多保留 720p，标记 `is_hot` 的 token 最多保留 1080p，行为与站点播放器一致。

正式配置屏蔽页面自行加载 manifest，避免它和显式 `playerContent` 授权链路并发抢占或产生无关请求。

## 错误边界

只接受数字视频 ID和 `latest`、`hottest`、`tag/{数字}` 分类。网络超时、非法参数和 HTTP 状态分别返回可识别消息；播放失败返回空 URL，而不是伪造可播放结果。签名 token 不写日志、不进文档，也不长期缓存。

`js/adapters.test.cjs` 覆盖首页标签、请求超时、空结果、geo 失败、非法分类、HTTP 失败和播放授权错误。`GMSubsTest` 覆盖 token 传播、授权域名、清晰度筛选和已有 token 不覆盖。正式手机内置播放、自然进度、快进和返回重播通过。

## 可复用经验

- 有结构化 API 时优先 API，不要重复解析前端 DOM。
- geo/授权参数通常是短期且与地区相关，必须每次按站点流程获取。
- 主清单 token 不一定自动进入相对子清单；要根据站点播放器行为精确改写。
- 所有外部 ID、分类和授权域名都应白名单校验，避免把模板变成任意请求器。
