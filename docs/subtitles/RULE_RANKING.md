## 接入位置与边界

`playerContent → 自有库优先 → 未命中时查迅雷 → 文件名排序 → 正文检查/排序 → 原五分钟缓存 → Result.subs`。库命中仍不查迅雷，不改变整库索引排序。这个接口同步返回，不是先播放再后台替换字幕；因此第一版正文检查最多额外等待 1500 ms，返回以后不自动切换。

沿用 OkHttp 的异步下载和每主机并发限制，不新建常驻线程池。只主动读取 `https://subtitle.v.geilijiasu.com:443`、无用户名密码的候选，禁止跟随重定向；其他 URL 仍保留但不主动探测。最多检查二十份，每份一 MiB、最多两万条。每次 HTTP 调用至多一秒，总等待还受宿主三十秒减两秒返回余量限制。到期取消未完成调用，迟到结果不能修改返回的列表。未完成、网络失败、重定向、超限或编码/结构不确定的文件保留为未评分候选；全部无证据时保持原顺序及数据。结果仍缓存五分钟/一百个番号，缓存期间不重复下载。

## 规则，不是翻译准确率

解析 SRT/VTT 时间戳及 ASS/SSA 的 Events/Format/Dialogue。严格解码 UTF-8 或带 BOM 的 UTF-16；GB18030/Big5 只有严格解码结果不冲突时才分析，冲突则不猜测。字幕原始字节、URL 和时间轴不修改。

基准分一百分；有效正文条数仅提供最多二十分的对数奖励，一千条封顶，不用文件大小或总条数直接判优。按比例扣除结束时间不大于开始时间、空条目、括号内音效说明/推广信息、长单字重复、NUL/替换字符/私用字符。中文优先，明显以假名、韩文、泰文或拉丁字母为主的版本降级；不足一百条正文再作轻度降级。括号本身不直接判成音效，而是结合声/音等关键词；这仍可能误判，不是语义分析。少量音效/署名也不是整份坏字幕的证据。文件名明确包含其他番号时额外降级，哈希文件名不猜测为串片。未评分候选用中间等级，稳定排序的同分候选保持原文件名/API 顺序。

只合并解析后每一条的可见文字和开始/结束毫秒完全相同的版本（SHA-256 指纹；忽略 BOM、换行、空白和格式标签）。文字不同或时间轴不同都保留；格式不完整、不支持或解码不确定的文件不参与合并。不会因为同名、同条数、同正文但时间整体平移而合并。原文件完全保留，不是删除原档。

已分析列表第一项设默认字幕，其余沿用库候选的选择标志。明确时轴异常的名称追加“时轴异常”；严重异常的追加“建议备选”，仍可手选。合并站点原字幕时保留原媒体地址、请求头和原字幕。

没有“色花堂/98堂/听译/人工”信任加分，没有 AI 调用或来源黑白名单。规则不能验证对照音轨的翻译准确性、人物名称改写、删减片源匹配或固定时间偏移。末条字幕时间也不是视频总时长，当前不据此自动对齐或认定缺失。
